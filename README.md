# Timish Dhage — Interactive AI/Data Portfolio

A premium, interactive portfolio website built with Next.js 14, TypeScript, Tailwind CSS, and Framer Motion.

## Quick Start

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deployment (Vercel)

1. Push to GitHub
2. Go to [vercel.com](https://vercel.com)
3. Import your repository
4. Deploy
